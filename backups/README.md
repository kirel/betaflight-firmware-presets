# Betaflight CLI Backups

Reference CLI dumps and diffs used to derive private presets.

- `dump_all`: full backup for restore/reference
- `diff_all`: settings differing from firmware defaults

Current devices:

- `air65-f`: BetaFPV Air65 F, BETAFPVG473, Betaflight 4.5.0
- `air75`: BetaFPV Air75, BETAFPVG473, Betaflight 4.5.0
